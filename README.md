# Frutinovela - Práctica de C#

Proyecto de consola en C# (.NET 8) con los 7 ejercicios de la práctica:

| # | Ejercicio | Archivo(s) |
|---|-----------|-----------|
| 1 | Sintaxis básica y variables | `Program.cs` |
| 2 | Estructuras de control | `Program.cs` |
| 3 | Clases y objetos | `Persona.cs` |
| 4 | Herencia | `Animal.cs`, `Perro.cs`, `Gato.cs` |
| 5 | Polimorfismo | `Program.cs` (usa `List<Animal>`) |
| 6 | Encapsulamiento | `CuentaBancaria.cs` |
| 7 | Interfaces y abstracción | `IVehiculo.cs`, `Carro.cs`, `Motocicleta.cs` |

## Cómo ejecutarlo

```bash
dotnet run
```

Se abre un menú para correr cada ejercicio por separado o todos a la vez (opción 8).
